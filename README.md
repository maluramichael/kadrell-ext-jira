# kadrell-ext-jira

Kadrell extension: your Jira Cloud tickets in the right sidebar. Open a ticket in the browser or start a session in its project folder. Set the Jira URL, account email, API token and JQL in the extension settings.

## Install

Inside [Kadrell](https://kadrell.malura.de), press `F4`, search under "Discover" for `kadrell-ext-jira` and click Install.

Or clone it by hand:

```bash
git clone https://github.com/maluramichael/kadrell-ext-jira ~/.config/kadrell/extensions/jira
```

Then enable it in the `F4` dialog.
